怎么装

复制卡片里的命令，在终端跑一遍；把包名加进 profile 的 dsh.profile.bundles，重启 DSH 即可。

📦

预构建包

每个插件的 GitHub Release 都挂着打包好的 .tgz，链接不带版本号，永远指向最新版。

🔍

插件市场里也能找到

插件都带 dsh-plugin topic，并已投稿 awesome-dsh-plugin（DSH 插件市场的数据源）。

提需求

想要什么功能，在对应仓库开 issue 说一声；鲸鱼娘吃白米饭，干活不挑食。
